# Session Log

## Goal
- Build a referral/affiliate program where customers earn commissions by promoting products, with admin-managed affiliates, per-category commission rates, and manual payouts.
- Peer-to-peer chat between customer and seller for marketplace orders (seller-side: marketplace sellers only; admin read-only; customer UI inside order-status page).

## Constraints & Preferences
- Affiliates created by admin only (no self-signup), codes auto-generated from name with hyphen format (e.g., `sara-ben-ali`) and numeric suffix for duplicates
- Admin sets each affiliate's password (plain text, hashed with SHA-256 on worker)
- Affiliate logs in via code + password on `affiliate.html` to view stats and request payouts
- No cookies for tracking; link sets `?ref=CODE` â†’ captured in sessionStorage, shown read-only at checkout (`Referred by: code`)
- Per-category commission (set via category editor, stored in `categories.commission_percent`), calculated when admin marks order as delivered
- Payouts manual: affiliate requests â†’ admin approves/rejects in panel
- Affiliate code IS the display name shown to customers (no separate lookup)
- Chat: one thread per order; only orders with marketplace items (non-empty `order_items.sold_by`) get chat; chat visible on order-status page when `chatAvailable`; sellers authenticated by session token; customer authenticated by orderId + phone; admin read-only view
- Chat is polling-based (10 s interval on customer page + seller modal + admin modal), no WebSocket/SSE; sender names: customer bubble = phone, seller bubble = `display_name`
- **Deployment: NO wrangler/CLI.** The user uploads `cloudflare-worker.js` manually via the Cloudflare dashboard (Workers & Pages → worker → Edit code → paste file contents → Deploy). Static site is pushed to GitHub Pages manually by the user. Never tell the user to run `wrangler` commands.

## Key Decisions
- Auto-completion clock starts at `delivered_at` (set when admin marks delivered or customer confirms; COALESCE keeps first delivery time); a customer "Report to admin" sets `disputed=1` which blocks BOTH auto-completion and payout approval until admin clicks "Resolve dispute"
- Warranty stored per product as JSON `warrantyDays` for catalog/marketplace products; `public_products.warranty_days` INTEGER for community products; clamp 0..3650
- Affiliate code = display name (hyphenated lowercase, e.g., `sara-ben-ali`) no separate lookup needed at checkout
- sessionStorage over cookies for referral tracking (ephemeral, cleared on tab close)
- Commission only triggers on delivery (not on order placement or payment)
- Per-category commission rates (set via category editor, stored in `categories.commission_percent`), calculated using product's category
- Chat is one thread per order scoped to `orders.id`, participants limited to customers owning the order (orderId + phone) and sellers whose `display_name` matches `order_items.sold_by`; admin sees chat read-only and can monitor unread customer messages (customer messages unread by any seller count as "unread"); message sends rate-limited via in-memory `chatSendTimes` map (3 s interval, 1000 char max, newlines collapsed)
